# Generated outputs

Keep new experiment outputs here or in the existing ignored `dynapm/results/`, `dynapm/reports/`, and generated `dynapm/data/` paths used by the scripts. Only this README is tracked in `results/`.

Use distinct directories for each experimental generation. Record source revision, environment, input identity, parameters, and completion status. Current causal development outputs require validation; they must not be represented as validated publication results. Cached summaries must be checked against their per-VM inputs before interpretation.
